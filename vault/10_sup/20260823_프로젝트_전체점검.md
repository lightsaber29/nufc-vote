## 1. 테스트 스위트 전멸 (Windows 경로 버그) — ✅ 해결 (2026-08-23)

### 1.1 증상

```
node --test "src/**/*.test.mjs"
→ not ok 55건 / ENOENT 110건 / AssertionError 0건
   path: 'C:\C:\Users\user\...\src\lib\polls\rating.ts'
```

원인 하나였다. 17개 테스트 파일이 아래 관용구를 썼다.

```js
const __dirname = path.dirname(new URL(import.meta.url).pathname)
```

Windows에서 `.pathname`이 `/C:/Users/...`를 주고, `path.join`이 앞에 cwd 드라이브를 또 붙여 `C:\C:\...`가 된다. **로직 실패는 0건** — 전부 이 경로 버그였다.

### 1.2 조치 — 경로 관용구 치환 (17파일)

`package.json`의 `engines`가 `node>=22.6.0`이라 `import.meta.dirname`으로 치환하면 import 추가도 필요 없다.

```js
- const __dirname = path.dirname(new URL(import.meta.url).pathname)
+ const __dirname = import.meta.dirname
- const root = path.resolve(path.dirname(new URL(import.meta.url).pathname), '../..')
+ const root = path.resolve(import.meta.dirname, '../..')
```

→ **55 fail → 2 fail.**

### 1.3 경로 버그가 가리고 있던 진짜 드리프트 3건

남은 2건은 경로 문제가 아니라 stale 어설션이었다. 셋 다 **코드가 맞고 테스트가 뒤처진** 경우로, 전부 `components/design-foundation.test.mjs`에 있었다.

| 죽은 어설션 | 원인 | 조치 |
|---|---|---|
| `assert.match(globals, /text-body-2-normal/)` | `ed4972a`가 `globals.css`의 `@apply` 버튼 2개를 `ui/button.tsx`로 이관. 토큰이 사라진 게 아니라 옮겨간 것 | 삭제 — 바로 위 `assert.match(button, /text-body-2-normal/)`이 이미 검증 |
| `/className="flex-1 px-5 pb-24 pt-4"/` (및 `pt-6` 쌍) | `25bb4ac`("로딩 화면 스켈레톤 반응형으로 변경")가 `px-5 pt-4 pb-24 sm:pb-10`으로 변경 | 현재값으로 갱신 |
